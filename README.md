# Química Fácil — Ácidos | 2º Ano do Ensino Médio

Plataforma educacional completa, interativa e gamificada focada no estudo aprofundado de **Ácidos** para estudantes do 2º ano do Ensino Médio e vestibulandos (ENEM, Fuvest, Unicamp).

🌐 **Acesse online:** [quimica-acidos.vercel.app](https://quimica-acidos.vercel.app)

---

## 🚀 Funcionalidades Principais

- **19 Capítulos Estruturados**: Da definição de Arrhenius, Bronsted-Lowry e Lewis até Chuva Ácida, Tampões Biológicos e Titulações.
- **100+ Exercícios Classificados por Nível**: Questões conceituais, cálculos de pH/Ka/alfa e questões de vestibulares comentadas.
- **30 Exercícios Resolvidos Passo a Passo**: Detalhamento didático desde a leitura do enunciado até a resolução matemática.
- **Simuladores Interativos**:
  - Escala de pH Interativa (ácidos do cotidiano, colorimetria de indicadores e concentração hidrogeniônica).
  - Calculadora e Simulador de Neutralização Total e Parcial com estequiometria balanceada.
- **Glossário Químico Completo**: Com pesquisa dinâmica em tempo real e tags por categoria.
- **Dashboard do Estudante (Gamificação)**:
  - Pontuação de XP e níveis de maestria.
  - Histórico de acertos/erros com estatísticas por tópico.
  - Conquistas desbloqueáveis e persistência no `localStorage`.

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou yarn

### Instalação e Execução

```bash
# Clone o repositório
git clone https://github.com/rafaelmendoncadev/quimica-acidos.git

# Acesse a pasta do projeto
cd quimica-acidos

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Abra no navegador em `http://localhost:5173`.

### Testes e Build

```bash
# Executar suíte de testes unitários
npm run test

# Gerar build de produção otimizado
npm run build
```
